01 Fonctions

Fonctionnalités principales.

Bloqueur de traqueurs intégré

Publicités, pixels espions, scripts d’analyse : coupés avant même d’être téléchargés. Le compteur à droite de la barre d’adresse montre ce qui a été arrêté, page par page. Ajoute ta propre liste en déposant un fichier texte.

Mode Tor

Tout le trafic passe par le réseau Tor. Si Tor tombe, plus rien ne sort : pas de fuite silencieuse.

HTTPS partout

Les sites en HTTP sont ouverts en HTTPS. Si un site ne le gère pas, Vipera te prévient avant de continuer.

DNS chiffré

Ton fournisseur d’accès ne voit plus la liste des sites que tu visites. Quad9, Cloudflare ou Mullvad au choix.

Zéro trace, par défaut

Pas d’historique, pas de cookies sur le disque, pas de cache : tout vit en mémoire et disparaît à la fermeture. Besoin de rester connecté quelque part ? Active « Garder les données » dans les réglages, et choisis d’effacer à chaque sortie.

Anti-empreinte

Canvas, carte graphique, écran, mémoire : les informations qui servent à te reconnaître sont brouillées ou uniformisées.

Recherche respectueuse

DuckDuckGo, Brave Search, Startpage, Qwant, Mojeek ou SearXNG. Jamais de moteur qui te profile imposé.

Interface moderne

Onglets fluides, recherche dans la page, raccourcis habituels, et les boutons rouge, jaune, vert en haut à droite.

02 Le trajet de tes données

Visibilité avec et sans Tor.

Sans Tor

Le site voit ton adresse IP. Ton fournisseur d’accès voit où tu te connectes (le DNS chiffré de Vipera lui cache déjà la liste des noms de sites, mais pas les adresses elles-mêmes). Les traqueurs, eux, sont bloqués.

Avec Tor

Ta connexion rebondit sur trois relais bénévoles, chiffrée en couches. Le site voit l’IP du relais de sortie, pas la tienne. La connexion est plus lente.

04 Installation

Installation par système.

  1. Télécharge Vipera.Setup.1.0.0.exe depuis la page des versions.
  2. Double-clique dessus. Si Windows affiche « éditeur inconnu » : Informations complémentaires puis Exécuter quand même. C’est normal, le programme n’est pas signé (la signature coûte cher, Vipera est gratuit).
  3. Suis l’assistant : dossier d’installation, raccourci bureau, c’est fait. Une version portable (sans installation) est aussi disponible.
Télécharger pour Windows
Ou compile-le toi-même : double-clique sur install.bat à la racine du projet.
  1. Télécharge Vipera.dmg depuis la page des versions.
  2. Ouvre le fichier et glisse Vipera dans Applications.
  3. Premier lancement : clic droit sur l’app, puis Ouvrir, puis confirme. macOS demande ça pour toute app non signée.
Télécharger pour macOS
Ou compile-le : bash install.sh
  1. AppImage (toutes distributions) : télécharge, puis chmod +x Vipera*.AppImage && ./Vipera*.AppImage
  2. Debian / Ubuntu : sudo apt install ./vipera*.deb
  3. Pour le mode Tor, rien à faire : Vipera sait télécharger Tor lui-même, ou utiliser celui déjà installé.
Télécharger pour Linux
Ou compile-le : bash install.sh

Mises à jour

Aucune mise à jour automatique en arrière-plan : c’est du réseau en plus. Télécharge la nouvelle version quand tu veux.

Désinstallation

Windows : Paramètres, Applications. Les données de Vipera sont supprimées avec lui. Sur macOS et Linux, supprime simplement l’application.

Vérifie le code

Le code source est disponible dans le dossier browser/ : une trentaine de fichiers, en JavaScript, sans dépendance cachée.

05 Transparence

Limites connues.

Pas d’anonymat parfait

Aucun navigateur ne peut le garantir. Si tu te connectes à ton compte personnel, le site sait qui tu es, Tor ou pas.

Pas de signature ni d’audit

Le projet est jeune et n’a pas été audité. Garde-le à jour et traite-le comme un outil au quotidien, pas comme un bouclier absolu.

Anti-empreinte partielle

On brouille les signaux les plus courants. Le Navigateur Tor, lui, uniformise tous ses utilisateurs : il reste plus fort sur ce point.

06 FAQ

Questions fréquentes.

Vipera est-il vraiment gratuit ?

Oui, pour toujours : licence MIT, aucune pub, aucun abonnement, aucune version payante cachée. Tu peux même le modifier et le redistribuer.

Quelle différence avec Brave ou Firefox ?

Brave et Firefox sont des navigateurs complets avec une grande équipe derrière. Vipera, c’est une approche « privé d’abord » : rien n’est enregistré par défaut, le DNS est chiffré dès le départ et Tor est intégré à l’interface.

Est-ce aussi sûr que le Navigateur Tor ?

Non. Le Navigateur Tor est conçu pour que tous ses utilisateurs se ressemblent, ce que Vipera ne fait qu’en partie. Vipera cache ton adresse IP via Tor, mais reste un navigateur de tous les jours.

Que se passe-t-il si Tor se déconnecte ?

Rien ne sort. Tant que Tor n’est pas prêt, les pages refusent de se charger au lieu de passer par ta connexion normale. Ce mécanisme évite toute fuite de trafic.

Mes mots de passe sont-ils enregistrés ?

Non, Vipera n’en enregistre aucun. Pour rester connecté entre deux sessions, active « Garder les données » dans les réglages. Utilise un gestionnaire de mots de passe externe pour le reste.

Pourquoi Windows ou macOS me met en garde ?

L’application n’est pas signée numériquement. Les étapes d’installation indiquent comment poursuivre.

Comment créer les installateurs moi-même ?

Windows : double-clic sur install.bat. macOS et Linux : bash install.sh. Ou pousse le projet sur GitHub : le fichier release.yml compile les trois systèmes gratuitement.
